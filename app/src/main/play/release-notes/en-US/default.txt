Syncthing-Fork (Compose Edition) — the full rewrite release.

## New
* **Complete UI rewrite**: Jetpack Compose + Material 3, single-Activity Navigation 3, folders / devices / status moved to a bottom navigation bar; all legacy View code removed
* **SAF bridge**: folders exposed by third-party DocumentsProviders (no real filesystem path, e.g. another app's data root) are bridged into the core and synced like any other folder
* **Root mode (experimental, off by default)**: run the core as root to sync any directory (e.g. other apps' data); root browse in the built-in folder picker; storage ownership is handed back automatically when root is switched off; su is requested with a confirmation dialog. See the wiki: Run-as-root-on-rooted-devices
* **AMOLED black theme**: system / light / dark / AMOLED with instant switching, embedded Web GUI included
* **38 languages at 100%** coverage, key order aligned across all packs

## Fixed
* Deep-link folder acceptance silently degraded to config.xml (web UI desync, duplicate pending folders)
* Editor drafts lost when covered by sub-pages; editor black screen on fast re-entry
* Forced kill of the core now reports "crashed (exit code 137)" instead of a fake active state
* Shutdown ANR: kill + join moved off the main thread
* Predictive back enabled with tuned transitions; double-back exit guard

## Engineering
* Service layer fully migrated to Kotlin + coroutines / Flow — zero Java in app sources; Dagger removed (manual DI), Volley/guava replaced by OkHttp
* 183 Robolectric unit tests; CI builds, signs and publishes releases

## Known limitations
* Root mode is experimental: verified on a single Magisk / HyperOS device; KernelSU untested
* Implicit broadcasts to AppConfigReceiver are blocked by Android 16 / HyperOS — use explicit broadcasts (see wiki)
* Dialogs have no predictive-back animation (compose-ui platform gap)

## 新增
* **界面全面重写**：Jetpack Compose + Material 3，单 Activity + Navigation 3，文件夹 / 设备 / 状态迁移到底部导航
* **SAF 桥接**：第三方 DocumentsProvider 的虚拟目录（如其他应用数据根）可直接同步
* **Root 模式（实验性，默认关闭）**：核心以 root 运行可同步任意目录；选择器支持 Root 浏览；关闭时自动交还文件所有权；开启时弹窗确认并请求 su 授权
* **AMOLED 纯黑主题**、**38 种语言 100% 覆盖**

## 修复
* 深链接受文件夹静默降级写 config.xml（webui 不同步、重复待确认）
* 编辑页被覆盖后草稿丢失、快速进出黑屏
* 核心被强杀现报"已崩溃（退出代码 137）"，不再假活跃
* 关停 ANR 修复；预测性返回开启并调优、双击返回防误退

## 已知限制
* Root 模式为实验性：仅在单台 Magisk/HyperOS 设备验证
